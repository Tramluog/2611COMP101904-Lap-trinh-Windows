# Bài tập lớp - Quản lý nhân viên

## 1. Mô tả

Xây dựng chương trình Console C# quản lý nhân viên, áp dụng các kiến thức về lập trình hướng đối tượng gồm:

- Class
- Property
- Constructor
- Encapsulation
- Kế thừa
- Đa hình

Chương trình quản lý các loại nhân viên:

- Nhân viên văn phòng
- Nhân viên kinh doanh
- Nhân viên thời vụ
